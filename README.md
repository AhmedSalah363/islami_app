# 🌙 Islami App

A Flutter-based Islamic mobile application that provides users with easy access to Quran pages, Hadith, and a digital Sebha in a simple and user-friendly interface.

## 📱 Features

### 📖 Quran
- Browse Quran Surahs through a dedicated Quran section.
- View Quran pages in a clean and readable interface.
- Navigate between different Surahs easily.

### 📿 Sebha
- Digital Sebha for counting Tasbeeh.
- Simple and interactive interface for tracking the count.

### 📚 Hadith
- Includes a collection of **50 Hadiths**.
- Browse Hadiths through a dedicated Hadith section.
- Simple layout designed for comfortable reading.

### 📻 Radio
- Radio feature is currently under development.
- The goal is to provide Quran audio streaming directly inside the application.
